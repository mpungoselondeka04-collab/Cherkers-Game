

# Checkers Game | Java

A Java-based implementation of the classic Checkers board game, developed to demonstrate object-oriented programming, logical problem-solving, and interactive application development.

The project focuses on applying programming concepts to a practical game environment, including board representation, player interactions, and game logic.

## Technologies Used
- **Programming Language:** Java
- **Development Environment:** Eclipse
- **Programming Concepts:** Object-Oriented Programming (OOP), Conditional Logic, Loops, and Event-Driven Programming

## Project Objectives
- Develop an interactive Checkers game using Java.
- Apply object-oriented principles to organise game components.
- Implement game logic and player interactions.
- Strengthen algorithmic thinking and debugging skills.

## Skills Demonstrated
- Java Programming
- Object-Oriented Design
- Problem-Solving
- Game Logic Implementation
- Debugging and Testing
